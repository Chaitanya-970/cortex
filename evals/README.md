# Evaluation Harness

Cortex evaluations should measure real agent behavior.

Suggested categories:

```text
evals/
├── coding/
├── tools/
├── multi-agent/
├── reliability/
└── security/
```

Useful metrics:

- task success
- test pass rate
- tool accuracy
- recovery rate
- latency
- token usage
- failure rate

Prefer deterministic success criteria wherever possible.
