# GitHub Development Workflow

```text
Issue
  ↓
Design / Discussion
  ↓
Branch
  ↓
Draft PR
  ↓
Commits + CI
  ↓
Code Review
  ↓
Changes / Approval
  ↓
Merge
  ↓
main
  ↓
Nightly Verification
```

Do not push directly to main.

Claim an open issue by commenting `.take` to be automatically assigned.

Required branch protection should include CI and review requirements.
